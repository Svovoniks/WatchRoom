  • Fresh self-contained Windows x64 test publish from the updated workspace source. Isolated instrumentation logs playback and invokes existing WPF handlers; application source files were not edited for this retest.
  • Separate host and VM profiles. The generated three-minute silent AVI exists only on the host.
